# Sistema Inteligente de Rutas Turísticas en Colombia

## Descripción

Este proyecto consiste en el desarrollo de un sistema inteligente capaz de encontrar rutas entre diferentes destinos turísticos de Colombia.

El sistema utiliza una base de conocimiento donde se almacenan los destinos, sus conexiones y un costo asociado a cada conexión.

Para realizar la búsqueda de rutas se utiliza el algoritmo A*, que combina el costo de la ruta recorrida con una estimación de lo que falta para llegar al destino.

El proyecto fue desarrollado como parte de la asignatura de Inteligencia Artificial.

## Objetivo

Desarrollar un sistema basado en conocimiento que permita encontrar una ruta entre dos destinos turísticos utilizando reglas y búsqueda heurística.

## Tecnologías utilizadas

- Python
- Visual Studio Code
- Git
- GitHub
- Algoritmo A*
- Búsqueda heurística
- Base de conocimiento
